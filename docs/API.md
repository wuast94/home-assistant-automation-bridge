# API reference

> Generated by `scripts/generate_docs.py`; do not edit manually.

Transport is the authenticated Home Assistant WebSocket API. Runtime calls use
the standard `call_service` WebSocket command.

## Entity definition

| Field | Type | Required | Default |
|---|---|---:|---|
| `unique_id` | `str` | yes | — |
| `platform` | `str` | yes | — |
| `name` | `str` | yes | — |
| `state` | `Any` | no | `None` |
| `attributes` | `dict[str, Any]` | no | empty collection |
| `device_identifier` | `str` | no | `'automation-runtime'` |

Platforms: `sensor`, `binary_sensor`, `switch`, `light`, `button`, `number`, `select`, `text`.

## Home Assistant actions

### `create_entity` — Create entity

Create a persisted dynamic entity, or reconcile an entity with the same unique ID.

| Field | Required | Selector |
|---|---:|---|
| `definition` | yes | `object` |

```json
{"definition":{"unique_id":"room-temperature","platform":"sensor","name":"Temperature","state":21.5}}
```

### `update_entity` — Update entity

Update selected fields of an existing entity definition.

| Field | Required | Selector |
|---|---:|---|
| `definition` | yes | `object` |

```json
{"definition":{"unique_id":"room-temperature","platform":"sensor","name":"Temperature","state":21.5}}
```

### `remove_entity` — Remove entity

Remove an entity definition, state, and entity-registry entry.

| Field | Required | Selector |
|---|---:|---|
| `unique_id` | yes | `text` |

### `command_result` — Return command result

Complete a pending entity command using its correlation ID.

| Field | Required | Selector |
|---|---:|---|
| `correlation_id` | yes | `text` |
| `success` | yes | `boolean` |
| `state` | no | `object` |
| `error` | no | `text` |

### `runtime_status` — Set runtime status

Mark all bridge entities available or unavailable.

| Field | Required | Selector |
|---|---:|---|
| `available` | yes | `boolean` |

### `list_entities` — List entities

Return all persisted entity definitions for reconciliation and diagnostics.

## Entity command event

Controllable entities emit `wuast_automation_bridge_command`.

```json
{"correlation_id":"…","unique_id":"runtime-switch","platform":"switch","command":"turn_on","value":null}
```

Return the result with `command_result` before `command_timeout` expires.
